Mudae Auto Roll is a auto hotkey program designed to automate the rolling process of the Discord game bot Mudae. 
This program is not integrated into Discord, the Mudae Dicord channel must be the active window for the duration of hotkey execution when the start hotkey is pressed. 
Double-click the exe to start the program, at which point a console window will open informing you the hotkey is now active. To terminate the program, just close the console window.
I recommend setting the exe file as a startup program if you regularly roll in Mudae channels on your device, so you don't have to find and open the execution file manually every time you turn-on your computer.
